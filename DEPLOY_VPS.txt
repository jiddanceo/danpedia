TAHAP 1 — PERSIAPAN AWAL VPS
================================================================================

1.1. Update sistem
    $ apt update && apt upgrade -y

1.2. Install dependencies dasar
    $ apt install -y curl wget unzip zip git nano ufw

1.3. Setting firewall (UFW)
    $ ufw allow OpenSSH
    $ ufw allow 'Nginx Full'
    $ ufw --force enable
    $ ufw status


================================================================================
TAHAP 2 — INSTALL PHP 8.3 + EKSTENSI LARAVEL
================================================================================

2.1. Tambah PPA Ondrej PHP
    $ apt install -y software-properties-common
    $ add-apt-repository ppa:ondrej/php -y
    $ apt update

2.2. Install PHP 8.3 dan ekstensi yang dibutuhkan
    $ apt install -y php8.3 php8.3-fpm php8.3-cli php8.3-common \
        php8.3-mysql php8.3-mbstring php8.3-xml php8.3-curl \
        php8.3-zip php8.3-bcmath php8.3-intl php8.3-gd \
        php8.3-tokenizer php8.3-fileinfo php8.3-dom php8.3-redis

2.3. Verifikasi
    $ php -v
    (harus tampil PHP 8.3.x)

2.4. Install Composer
    $ curl -sS https://getcomposer.org/installer | php
    $ mv composer.phar /usr/local/bin/composer
    $ composer --version


================================================================================
TAHAP 3 — INSTALL MYSQL
================================================================================

3.1. Install MySQL Server
    $ apt install -y mysql-server

3.2. Amankan instalasi
    $ mysql_secure_installation
    (ikuti prompt: set root password, hapus anonymous user, dsb)

3.3. Buat database dan user untuk aplikasi
    $ mysql -u root -p
    
    Jalankan di dalam MySQL:
    CREATE DATABASE danpedia CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    CREATE USER 'danpedia'@'localhost' IDENTIFIED BY 'PASSWORD_ANDA';
    GRANT ALL PRIVILEGES ON danpedia.* TO 'danpedia'@'localhost';
    FLUSH PRIVILEGES;
    EXIT;

3.4. (Jika restore dari backup) Import dump SQL
    $ mysql -u danpedia -p danpedia < /path/to/danpedia_db_YYYYMMDD.sql

================================================================================
TAHAP 6 — DEPLOY LARAVEL BACKEND
================================================================================

6.1. Upload atau clone kode backend ke server
    $ mkdir -p /var/www
    $ cd /var/www
    $ git clone https://github.com/REPO_ANDA/Laravel_Backend.git
    ATAU upload via SCP/SFTP lalu extract

6.2. Masuk ke folder backend
    $ cd /var/www/Laravel_Backend

6.3. Copy file environment
    $ cp .env.example .env

6.4. Edit file .env sesuaikan dengan konfigurasi server
    $ nano .env

    Poin penting yang wajib diisi:
    APP_ENV=production
    APP_DEBUG=false
    APP_URL=https://api.dan-pedia.com

    DB_CONNECTION=mysql
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE=danpedia
    DB_USERNAME=danpedia
    DB_PASSWORD=PASSWORD_DB_ANDA

    MAIL_MAILER=smtp
    MAIL_HOST=smtp.gmail.com
    MAIL_PORT=587
    MAIL_USERNAME=email@gmail.com
    MAIL_PASSWORD=APP_PASSWORD_GMAIL

    FRONTEND_URL=https://dan-pedia.com
    JWT_SECRET=(akan di-generate di langkah berikutnya)

6.5. Install dependencies PHP
    $ composer install --no-dev --optimize-autoloader

6.6. Generate app key dan JWT secret
    $ php artisan key:generate
    $ php artisan jwt:secret

6.7. Jalankan migrasi database
    $ php artisan migrate --force

6.8. Jalankan seeder (jika ada data awal)
    $ php artisan db:seed --force

6.9. Set permission folder storage dan cache
    $ chown -R www-data:www-data /var/www/Laravel_Backend
    $ chmod -R 755 /var/www/Laravel_Backend
    $ chmod -R 775 /var/www/Laravel_Backend/storage
    $ chmod -R 775 /var/www/Laravel_Backend/bootstrap/cache

6.10. Buat symbolic link storage
    $ php artisan storage:link

6.11. Cache konfigurasi untuk production
    $ php artisan config:cache
    $ php artisan route:cache
    $ php artisan view:cache
    $ php artisan optimize


================================================================================
TAHAP 7 — KONFIGURASI NGINX UNTUK BACKEND
================================================================================

7.1. Buat file konfigurasi Nginx untuk backend
    $ nano /etc/nginx/sites-available/danpedia-api

    Isi dengan:
    ----------
    server {
        listen 80;
        server_name api.dan-pedia.com;

        root /var/www/Laravel_Backend/public;
        index index.php;

        location ~ /\. { deny all; }

        location / {
            try_files $uri $uri/ /index.php?$query_string;
        }

        location ~ \.php$ {
            include snippets/fastcgi-php.conf;
            fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        }

        add_header X-Frame-Options "SAMEORIGIN";
        add_header X-Content-Type-Options "nosniff";
    }
    ----------

7.2. Aktifkan konfigurasi
    $ ln -s /etc/nginx/sites-available/danpedia-api /etc/nginx/sites-enabled/
    $ nginx -t
    $ systemctl reload nginx

================================================================================
TAHAP 9 — KONFIGURASI NGINX UNTUK FRONTEND
================================================================================

9.1. Buat file konfigurasi Nginx untuk frontend
    $ nano /etc/nginx/sites-available/danpedia-frontend

    Isi dengan:
    ----------
    server {
        listen 80;
        server_name dan-pedia.com www.dan-pedia.com;

        access_log /var/log/nginx/danpedia-frontend.access.log;
        error_log /var/log/nginx/danpedia-frontend.error.log;

        location / {
            proxy_pass http://127.0.0.1:3000;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection upgrade;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_cache_bypass $http_upgrade;
            proxy_read_timeout 86400;
        }

        location /_next/static {
            proxy_pass http://127.0.0.1:3000;
            add_header Cache-Control "public, max-age=31536000, immutable";
        }

        location ~ /\. { deny all; }
    }
    ----------

9.2. Aktifkan konfigurasi
    $ ln -s /etc/nginx/sites-available/danpedia-frontend /etc/nginx/sites-enabled/
    $ nginx -t
    $ systemctl reload nginx

TAHAP 11 — KONFIGURASI QUEUE WORKER (OPSIONAL)
================================================================================

Digunakan untuk: pengiriman email, notifikasi WhatsApp, job Digiflazz

11.1. Jalankan queue worker dengan PM2
    $ cd /var/www/Laravel_Backend
    $ pm2 start "php artisan queue:work --sleep=3 --tries=3 --daemon" --name "laravel-queue"
    $ pm2 save

    ATAU gunakan Supervisor:
    $ apt install -y supervisor

    Buat file konfigurasi:
    $ nano /etc/supervisor/conf.d/laravel-queue.conf

    Isi:
    ----------
    [program:laravel-queue]
    command=php /var/www/Laravel_Backend/artisan queue:work --sleep=3 --tries=3
    autostart=true
    autorestart=true
    user=www-data
    redirect_stderr=true
    stdout_logfile=/var/log/supervisor/laravel-queue.log
    ----------

    $ supervisorctl reread
    $ supervisorctl update
    $ supervisorctl start laravel-queue

PROSEDUR UPDATE KODE (SETELAH LIVE)

UPDATE BACKEND
--------------
1. Upload file yang berubah via SCP:
   pscp -pw PASSWORD file.php root@IP:/var/www/Laravel_Backend/path/file.php

$ systemctl reload nginx

TROUBLESHOOTING
================================================================================

Error "500 Internal Server Error" pada Laravel
→ $ cat /var/www/Laravel_Backend/storage/logs/laravel.log | tail -50
→ Pastikan .env sudah benar, jalankan: php artisan config:clear

Error "502 Bad Gateway" pada Frontend
→ $ pm2 list  (cek apakah danpedia online)
→ $ pm2 restart danpedia
→ $ pm2 logs danpedia

Error PHP Permission
→ $ chown -R www-data:www-data /var/www/Laravel_Backend/storage
→ $ chmod -R 775 /var/www/Laravel_Backend/storage

Log Nginx
→ $ tail -f /var/log/nginx/danpedia-frontend.error.log
→ $ tail -f /var/log/nginx/error.log

Log Laravel
→ $ tail -f /var/www/Laravel_Backend/storage/logs/laravel.log

Log PM2 NextJS
→ $ pm2 logs danpedia --lines 50
